# Corebound

Set 100 years in the future, NASA is sending out another spacecraft to study the asteroid named Psyche. However, this time there is a lonely robot that is in charge of the ships maintenance. Complete tasks around the ship and collect fact cards about Psyche to help the mission prevail! This is a 2D, single player experience for computer web browsers. Created in Unity with C# and used GitHub for version control.

Sponsored by the NASA Psyche Mission to create a fun and engaging way to educate the public about the mission as part of my senior capstone project at Seattle University.
